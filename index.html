One-time setup

This copy of the app has no Google client ID yet. Create one in the Google Cloud console, then paste it below.

  1. Create a project and enable the Google Drive API.
  2. Under Google Auth Platform set up branding, choose audience External, add the scope …/auth/drive.file, and publish the app.
  3. Create an OAuth client of type Web application with
